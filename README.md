# منصة قواعد السلوك والمواظبة — منصة تفاعلية (PWA)

منصة ويب عربية (RTL) تعمل بالكامل داخل المتصفح، وبُنيت اعتمادًا على الملف:

> **«قواعد السلوك والمواظبة لطلبة التعليم العام» — الإصدار الخامس ١٤٤٧هـ / ٢٠٢٥م**
> وزارة التعليم — المملكة العربية السعودية.

📱 **تطبيق ويب تقدّمي (PWA):** يُثبَّت على الجوال والحاسوب، ويعمل **بدون إنترنت**،
ويظهر بأيقونته على الشاشة الرئيسية بملء الشاشة.

---

## التشغيل

### الطريقة الأولى — فتح مباشر
اضغط نقرًا مزدوجًا على `index.html`. تعمل المنصة بالكامل من داخل المتصفح.

> ⚠️ **التثبيت والعمل بدون إنترنت يعملان عبر سيرفر محلي فقط**
> (الطريقة الثانية). عند الفتح المباشر لن يظهر خيار التثبيت.

### الطريقة الثانية — سيرفر محلي (موصى به)
شغّل `تشغيل المنصة.bat` (أو نفّذ `python -m http.server 8791` داخل هذا المجلد)،
ثم افتح: `http://127.0.0.1:8791/index.html`

> **لا تحتاج المنصة إلى اتصال بالإنترنت.** مكتبة قارئ PDF وكل البيانات
> مضمّنة داخل المجلد، ولا تغادر بياناتك جهازك إطلاقًا.

## صفحات المنصة

### 1) `index.html` — الصفحة الرئيسية
| القسم | المحتوى |
|---|---|
| 📕 **ملف الدليل** | بطاقة بأيقونة **PDF** مع ثلاثة أزرار: **عرض الملف** داخل المنصة، **تنزيل الملف**، **فتح في تبويب** |
| 🎯 الأهداف | الهدف العام وسبعة أهداف تفصيلية (المادة 2) |
| 👥 الأدوار | بطاقات قابلة للفتح لكل دور، مع رابط للصفحة التفصيلية |
| 📖 التعريفات | ٢٢ تعريفًا بصيغة بطاقات (المادة 1) |
| 🧭 تقييم السلوك | درجات المشكلات الخمس، السلوك الإيجابي والمتميز، مجالات السلوك المتميز (المادة 5) |
| 🗂️ النماذج | ١٧ نموذجًا مرفقًا بالدليل |
| 🔍 البحث | بحث فوري في كل عناصر الصفحة مع إخفاء الأقسام غير المطابقة |

**عارض PDF المدمج** يدعم: التنقل بين الصفحات (٧٥ صفحة)، التكبير والتصغير،
السحب بالتمرير، اختصارَي `←` و`→` للتنقل، و`Esc` للإغلاق.

### 2) `roles.html` — الصفحة الفرعية
| القسم | المحتوى |
|---|---|
| 🧮 حاسبة الغياب | أدخل عدد الأيام ونوع الغياب (بعذر / بدون عذر) لتظهر الإجراءات والدرجات المخصومة فورًا |
| 👥 الأدوار | **المعلم**، **المدير**، **ولي الأمر**، المرشد الطلابي، لجنة التوجيه الطلابي، الطالب، قسم التوجيه الطلابي بالإدارة — كلها **كنقاط** |
| 📋 المادة (31) | تقييم المواظبة: نقاط المعيار وقواعد حصر المواظبة |
| 📋 المادة (32) | جدول حالات الغياب والاستئذان بعذر وإثباتاتها |
| 📋 المادة (33) | جدول إجراءات التعامل مع الغايبين **بعذر** (٣ / ٥ / ١٠ أيام) |
| 📋 المادة (34) | جدول **درجات المواظبة** المخصومة + إجراءات التعامل مع الغايبين **بدون عذر** (٣ / ٥ / ١٠ أيام) |
| 📋 المادة (35) | اثنا عشر بندًا لأيام المواظبة العامة |
| 🗂️ النماذج | نموذجان: إجراءات الغياب بعذر وبدون عذر |

أزرار **فتح الكل** و**إغلاق الكل** لتحميل الأدوار كاملة، وبحث فوري في الصفحة.

## 📱 التثبيت على الجوال والحاسوب

عبر الموقع المنشور (أو السيرفر المحلي):

| الجهاز | الطريقة |
|---|---|
| **أندرويد / كمبيوتر** | يظهر زر **«📲 ثبّت التطبيق»** في الأعلى ← اضغطه ← تأكيد |
| **آيفون / آيباد** | Safari ← زر **المشاركة** ← **«إضافة إلى الشاشة الرئيسية»** |

بعد التثبيت:
- يفتح التطبيق **بملء الشاشة** بدون شريط متصفح.
- يعمل **بدون إنترنت** تمامًا.
- يظهر **اختصار «الأدوار والغياب»** عند الضغط المطوّل على الأيقونة.

> 💡 **لتوفّر دليل PDF بدون إنترنت:** افتح الدليل مرة واحدة **متصلًا** من زر
> «عرض الملف»، فيُحفظ على جهازك ويبقى متاحًا دائمًا بعدها.
> (حجمه ١٫٨ ميجابايت، ويُخزَّن في ذاكرة جهازك لا على المنصة.)

### تحديث المنصة
عند رفع نسخة جديدة، تظهر رسالة **«يتوفر تحديث جديد»** — اضغط **«تحديث الآن»**.
لا يمكن للتطبيق أن يستبدل نفسه تلقائيًا لئلا يفاجئ المستخدم بتغيير أثناء عمله.

## تعديل المحتوى

كل النصوص في ملفات `assets/js/data-*.js`، وكل ملف يحمل كائنًا واحدًا فقط،
فتعديل أي بند لا يحتاج لمساس ببقية الواجهة:

| لتعديل | افتح |
|---|---|
| التعريفات | `data-02-defs-a.js` و `data-03-defs-b.js` |
| دور المعلم | `data-05-role-teacher.js` |
| دور المدير | `data-04-role-manager.js` |
| دور ولي الأمر | `data-06-role-parent.js` |
| إجراءات الغياب | `data-09` … `data-13` |

بعد أي تعديل، شغّل أداة الفحص للتأكد من سلامة النصوص العربية:

```
python tools/check-data.py
```

تخرج الأداة `TOTAL SUSPECT STRINGS: 0` عند خلو الملفات من أي نص غير سليم.
